# Canvas Atelier 1.6.66

这是一次设置界面与 RelayMe 兼容操作的修复版本。

## 本版重点

### RelayMe 高级兼容方式

- 修复高级兼容说明和按钮被压缩成竖排的问题。
- 兼容方式现在明确作为旧版接口的备用入口，不会与 RelayMe 账号登录混淆。
- “打开 RelayMe 工作台”“登录/退出 RelayMe”“配置隐藏密钥”按钮保持清晰的横向布局。

### 模型目录

- RelayMe 目录只显示当前供应商的有效模型，不再混入 Comfly 旧目录。
- 当前账户目录验收结果：7 个模型、7 个启用（3 个生图、3 个视频、1 个对话）。

### 生图任务状态

- RelayMe 使用独立安全任务映射目录，避免与 Comfly 加密记录互相冲突。
- 历史失败任务不会被伪装成成功；重新发起任务时，界面会保留真实失败原因。

| --- | --- |

更新仍需在“设置 → 同步 → 高级故障排查 → 检查更新”中显式下载并重启安装，不会静默安装。

当前 Windows 安装包未配置 Authenticode 证书，请从 GitHub Release 下载并核对 SHA-256。
