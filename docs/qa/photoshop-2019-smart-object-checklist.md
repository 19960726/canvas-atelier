## 基础错误状态

- [ ] 未安装 Photoshop 时显示“未找到 Photoshop 2019 或更高版本”。
- [ ] Photoshop 已安装但未运行时显示“请先启动 Photoshop 并打开目标文档”。
- [ ] 运行版本低于 20 时显示“当前 Photoshop 版本过低，仅支持 2019 及以上版本”。
- [ ] Photoshop 已运行但无活动文档时显示“请先在 Photoshop 中打开 PSD 或 PSB 文档”。
- [ ] 自动化权限被拒绝时显示固定中文提示，不显示路径、用户名、脚本栈或命令。

## PSD 与 PSB

- [ ] Photoshop 2019 当前 PSD 导入成功。
- [ ] Photoshop 2019 当前 PSB 导入成功。
- [ ] 较新 Photoshop 当前 PSD 导入成功。
- [ ] 较新 Photoshop 当前 PSB 导入成功。
- [ ] 导入始终进入当前活动文档，不创建新文档。
- [ ] 导入后不自动保存、覆盖或关闭文档。

## 尺寸、比例与定位

- [ ] 小于画布的横图保持原始像素尺寸并居中。
- [ ] 小于画布的竖图保持原始像素尺寸并居中。
- [ ] 小于画布的方图保持原始像素尺寸并居中。
- [ ] 大于画布的横图等比例缩小到画布内并居中。
- [ ] 大于画布的竖图等比例缩小到画布内并居中。
- [ ] 大于画布的方图等比例缩小到画布内并居中。
- [ ] 图片没有裁切、拉伸、非等比缩放或偏离中心。

## 图层与资产

- [ ] 新图层是嵌入式智能对象，不是链接智能对象。
- [ ] 图层名来自已清理的安全资产标签。
- [ ] 使用生成原图，不使用缩略图或预览 URL。
- [ ] 导入后原始受管图片未被删除、移动或修改。
- [ ] 视频、导入图片、缺失原图和跨项目资产均被拒绝。

## 并发与交互回归

- [ ] 连续点击同一图片只提交一次，按钮显示“正在导入…”。
- [ ] 同一图片重复进行中的请求返回“这张图片正在导入 Photoshop”。
- [ ] 不同图片按顺序导入，不同时操作活动文档。
- [ ] 导入前后的系统剪贴板内容完全一致。
- [ ] 画布复制图片、复制视频、桌面粘贴、Agent 粘贴仍可使用。
- [ ] 下载图片、发送到 AI 对话、双击完整预览仍可使用。
- [ ] 浅色和深色主题下菜单、忙碌状态和结果提示均清晰可读。
