# Canvas Atelier 1.6.184 验收记录

## 修复内容

- AI 分层按钮随图片输入节点悬停或键盘聚焦显示，离开并失焦后收起。原水杯大项目节点和新粘贴节点均在实际桌面程序中检查。
- 七层返图内容重叠时继续阻止正式合成，提供明确标记的待修整 PSD：原图默认可见，候选背景和前景层隐藏。缺少原图位置的旧层不会错误显示草稿导出入口。
- Nano Banana 2 的 4096×4096 图片在中性自动校色时不再被无意义转码拦截；非中性校色也可在 Photoshop 中以原位、原比例的智能对象导入。
- 复制图片去掉主进程重复 PNG 编码；校色下载在 Web Worker 处理完整像素并显示处理中状态。
