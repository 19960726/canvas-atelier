# 画布完整项目保存、统一历史与 Photoshop 智能对象中文实施计划

> **执行要求：** 实施时必须使用 `superpowers:executing-plans`，按照任务顺序逐项执行。每个任务均采用“先写失败测试 → 最小实现 → 回归验证 → 独立检查点”的方式推进。

**目标：** 完成生图/视频参数规范、设置模型列表整理、独立项目完整保存、最近项目管理、Comfly/RelayMe 统一图片与视频历史，以及 Photoshop 2019+ 嵌入式智能对象导入。

**总体架构：** 渲染层只负责界面和受控请求，不直接接触真实文件路径、API 密钥或 Photoshop 脚本。项目路径、媒体文件、API 结果下载、历史文件和 Photoshop 自动化全部由可信桌面进程管理。继续复用现有 `ProjectRepository`、生成历史仓库、供应商注册表和 Figma 风格画布组件，不创建第二套重复系统。

**技术栈：** TypeScript、React、Zustand、Electron IPC/Preload、Zod、Node.js 文件系统、Vitest、Testing Library、Playwright、Photoshop ExtendScript/JSX。

## 全局硬性要求

- 生图清晰度只显示 `2K / 4K`，旧项目中的 `1K` 自动迁移为 `2K`。
- 生图和视频使用同一套带图标的比例选择器，并支持 `AUTO` 智能比例。
- 模型列表每行只显示“复选框 + 模型名称”，不显示网站名和能力徽标。
- 项目必须保存上传图片、上传视频、生成图片、生成视频、反推内容、提示词、模型参数、节点位置和连线。
- 最近项目和当前项目恢复版本必须分开显示。
- Comfly 与 RelayMe 的图片、视频结果必须进入同一套真实历史记录。
- Photoshop 仅支持 Windows Photoshop 2019+，导入方式为嵌入式智能对象。
- 项目文件不得包含 API 密钥、Authorization、危险 URL、任意脚本或不受控绝对路径。
- 自动化测试不得发送真实付费生图或视频请求。
- 工作区已有大量用户修改，严禁 reset、checkout 或清理无关文件。

### Photoshop 行为

- 生成图片右键显示“导入 Photoshop（智能对象）”。
- 使用原始受管图片，不使用缩略图。
- 导入当前已打开的 PSD/PSB。
- 使用嵌入式智能对象，不使用链接智能对象。
- 图片小于 PSD 画布：保持原始像素尺寸并居中。
- 图片大于 PSD 画布：等比例缩小到画布内并居中。
- 禁止拉伸、裁切和改变宽高比例。
- Photoshop 未安装、版本过低、未启动或没有文档时显示明确中文提示。
