# 批量框选素材并连接功能节点设计

## 背景

用户需要复现参考视频中的工作流：在画布上框选多个图片或视频节点，随后从功能节点菜单选择图片生成、视频生成或 Agent 反推，系统自动创建目标节点，并将框选素材按稳定顺序连接到目标节点的素材输入槽。

本次同时收敛此前反复出现的交互问题：任意位置 `@` 引用、反推任务编辑框滚动、复制粘贴素材、按钮间距和尺寸、节点越界/重影、缩略图卡顿、小地图定位以及视频和反推工作台回归。

## 目标与非目标

### 目标

1. 支持框选多个素材节点后批量创建并连接功能节点。
2. 对素材建立确定且可复现的顺序：从上到下，同一行从左到右；相同坐标时使用节点 id 作为稳定 tie-breaker。
3. 只连接目标节点兼容的输入端口；不兼容节点跳过并给出可见提示。
4. 已有目标节点素材不被覆盖，新素材追加到现有输入顺序末尾。
5. 反推执行时，将所有连接并被 `@图片N` / `@视频N` 引用的媒体按顺序传给模型，并要求结构化输出逐素材职责。
6. 让 `@` 引用不依赖文本末尾或最后一个已有芯片；引用编辑器具有独立滚动容器并阻止滚轮传递到画布。
7. 通过自动化测试和安装包构建验证，不破坏现有未提交改动。

### 非目标

- 不改变模型供应商协议或凭证管理。
- 不自动覆盖用户已有素材顺序。
- 不把不兼容的文本、结果或控制节点强制转换为图片/视频输入。
- 不在本次重写整个画布导航栏，只修复影响批量选择和节点定位的交互契约。

## 用户流程

1. 用户在画布使用框选工具选择多个节点。
2. 画布保留 React Flow 的节点选择状态，并在选择包含可连接媒体时显示批量操作入口。
3. 用户打开功能节点菜单并选择目标节点类型。
4. 系统创建目标节点；位置优先使用当前视口安全中心或选择区域右侧的安全位置，避免节点越界和遮挡选择框。
5. 系统按稳定排序遍历选中节点，针对每个节点寻找目标类型的兼容多输入端口，按当前目标已有输入数量追加 `order`，创建持久化边。
6. 连接完成后，目标节点的缩略图槽立即按照同一顺序刷新；失败的边不影响已成功的边，并以一次性状态提示报告跳过原因。
7. 反推节点运行时，按持久化边的 `order` 生成 `@图片1`、`@图片2`、`@视频1` 等对应关系，并构造包含全部引用媒体的模型请求。

## 顺序与兼容性

排序键为：

1. `position.y` 升序；
2. `position.x` 升序；
3. 节点 id 字典序。

兼容性由领域层端口定义和现有 `canConnectCanvasPorts` 校验共同决定。图片输入、上传图片和图片结果可连接到图片生成参考、视频媒体或反推引用；视频输入/视频结果只连接到视频媒体或反推视频/引用端口。连接前必须检查目标端口是否为 `inputMany`，并且不超过项目媒体上限。

## 反推逐素材职责

反推请求中的 `references` 和 `orderedMedia` 使用同一顺序。每个引用必须保留：`mention`、`sourceId`、`label`、`position/order`、媒体类型及受管资产身份。

结构化结果必须包含逐素材职责记录。每条记录至少说明：

- 对应的 `@图片N` / `@视频N` 与素材名称；
- 该素材提供的是主体、场景结构、道具、材质、人物姿态、灯光、构图或其他信息；
- 可继承元素；
- 与其他素材的冲突；
- 在最终场景中的位置、层级和作用。

缺少任何已引用素材的职责记录时，结果标记为不完整并保留可重试状态，不静默当作成功。

## `@` 引用编辑器

- 监听光标所在输入框的 `@` 输入，不以全文最后一个 `@` 判断。
- 已有完整芯片后，在芯片前、中间或后方新增 `@` 都必须打开菜单。
- 菜单无匹配文本时仍展示当前节点可用的已连接媒体候选。
- 选择候选只替换当前未完成引用，不改变其他已完成芯片。
- 编辑器固定可视高度，内容区域 `overflow-y: auto`，滚轮事件在编辑器内部消费并使用 `overscroll-behavior: contain`。

## 错误处理与性能

- 没有可连接媒体时不显示批量连接入口。
- 所有边连接使用单个事务/稳定队列，避免连续持久化造成卡顿。
- 图片缩略图使用懒加载和异步解码；超过阈值时保持可见性裁剪。
- 连接失败、超出 20 个素材或端口不兼容时显示明确原因，不弹文件选择器、不创建孤立节点。
- 批量操作期间保留撤销边界，用户一次撤销即可撤销本次创建和连接。

## 测试策略

### 单元与组件测试

- 选择排序：不同坐标、相同坐标和混合节点类型。
- 批量创建：图片生成、视频生成、反推三个目标类型的边和 `order`。
- 兼容性：不兼容节点跳过，已有输入追加，不覆盖原顺序。
- `@`：已有芯片前插入、句中插入、标点前插入、无匹配文本回退候选、多处引用只替换当前未完成引用。
- 滚轮：编辑器消费 wheel，父级画布不收到 wheel；CSS 高度和 overflow 契约存在。
- 反推：所有引用媒体进入 ordered request，逐图职责缺失会被标记不完整。

### 集成与视觉回归

- 框选后选择功能节点的端到端流程。
- 20+ 图片节点批量连接时不冻结画布。
- 视频节点、反推节点、素材缩略图和小地图回归。
- 按钮高度、间距、节点边界、重影和导航定位回归。

### 发布验收

- 相关 Vitest 全通过。
- 类型检查和生产构建通过。
- NSIS 安装包生成成功并记录 SHA256。
