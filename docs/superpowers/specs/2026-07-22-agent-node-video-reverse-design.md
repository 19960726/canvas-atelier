# Agent 节点与视频直传反推设计

## 目标

让画布中的 Agent 反推节点成为模型路由、角色定位、任务需求与知识库选择的唯一编辑来源，并让受管 MP4 原视频能够作为多模态模型的原始输入完成反推。

## 配置与运行边界

- `ReverseAgentNodeConfig` 持久化 `modelRoute`、`role`、`task` 与恰好两个 `knowledgeBaseIds`。
- 节点编辑使用本地草稿；只有“应用任务”动作写入项目，因此输入过程不创建项目提交。
- 知识租约只固定节点选定的两份、状态可用且具有活动版本与内容哈希的知识库。
- 右侧 Agent 抽屉只读取已选中的反推节点并启动运行；它不保存另一份角色或任务配置。
- 视频输入仅接受已由桌面安全导入流程管理的 MP4 资产。运行请求携带原视频资产，而非本地路径、外部 URL 或抽帧结果。
- 反推路由必须声明 `reverse_prompt` 与 `video_understanding` 能力；无兼容路由、没有媒体、视频不合规或两份知识库未就绪时不得运行。
- 测试只使用模拟传输层；不在验证中调用付费模型。

## 运行数据流

1. 用户导入 MP4 并在画布上将视频输入连接至 Agent。
2. 用户在 Agent 节点设置路由、角色、任务与两份知识库，点击“应用任务”。
3. 右侧 Agent 读取当前选中的节点，验证连线和配置，建立只含所选知识库快照的租约。
4. Provider 适配器将结构化角色/任务、图片引用和原视频资产发送到兼容的多模态接口。
5. 运行记录固定模型路由、媒体标识、任务配置、知识版本与返回结果，供 Agent 抽屉和历史查看。

## UI

输入、生成和输出节点保持图像优先、低噪声和外置端口。Agent 为紧凑表单卡片：模型、角色、任务、双知识库、执行状态和端口。浅/深主题中均保留可见焦点、错误与锁定状态，不复制第三方品牌或素材。

## 非目标

不进行本地抽帧或自动降级；不上传任意本地路径；不新增打包、portable、installer 或付费模型调用；不改动画布视口或节点位置来执行反推。
