# 桌面桥接、项目保存、模型服务与生成节点恢复设计

## 目标

恢复安装版的完整桌面能力，并统一生图/视频节点：项目可持久保存且可从“最近项目”恢复；Comfly 与 RelayMe 可安全保存密钥、检测连接并加载模型；窗口单击即可安全关闭；生成节点遵循用户确认的紧凑连接节点规范。

## 已确认根因

安装包中的 `preload.js` / `safe-preload.js` 以 ESM 形式输出，但桌面窗口启用了 Electron `sandbox: true`。沙箱 preload 未建立 `window.novusDesktop`，因此项目仓库、最近项目、凭据保险库、模型目录和关闭协调器在渲染端全部不可用。当前构建测试只验证了主进程产物，没有在真实沙箱窗口中验证 preload API。

## 桌面桥接

- 将现代版和兼容版 preload 构建为沙箱可执行的 CommonJS 脚本。
- 保持 `contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`，不以关闭沙箱规避问题。
- 增加构建产物合同测试，禁止 preload 含顶层 ESM `import`，并验证 `novusDesktop` 暴露面。
- 增加打包后的 Electron 烟雾测试，确认安装包窗口内项目、provider、生命周期 API 均存在。

## 项目保存与历史恢复

- 显式“保存项目”必须创建或更新持久项目，成功后立即刷新最近项目列表。
- “新建项目”只创建新的内存工作区，不删除最近项目索引或旧项目文件。
- 项目包含节点、连线、提示词、反推结果、生成图片/视频引用和相关元数据。
- 启动时检测旧版 `@agent-canvas/desktop-modern` 数据目录；只读发现并迁移可识别的项目索引，避免覆盖新目录数据。
- 保存失败必须在按钮附近显示中文错误，不允许静默返回成功。

## Comfly 与 RelayMe

- 每个供应商独立保存一把隐藏密钥；当前选中的供应商只使用自己的密钥。
- 保存后执行连接检测，再刷新该供应商模型目录。
- 模型按生图、视频、对话、反推、视觉、视频理解分类；相同显示模型去重但保留供应商路由映射。
- UI 只显示模型名称，不在节点选择器中重复显示网站名称。
- 未连接、鉴权失败、目录为空和网络失败分别显示明确中文状态。
- 模型目录使用紧凑分类列表，不再为每个能力显示巨大空卡片。顶部展示当前供应商、连接状态和模型总数；有模型时按能力分组显示模型名、能力和启用状态；没有模型时只显示一个统一空态，并提供“配置密钥”和“重新检测”入口。

## 关闭流程

- 点击窗口关闭只发起一次协调关闭请求。
- renderer 收到请求后只执行一次最终保存并返回 ACK。
- preload 不可用或保存失败时只出现一次恢复选择，不允许反复点击触发多个并发关闭请求。
- 保存成功后立即销毁窗口；取消则保持窗口不变。

## 生图与视频连接节点

- 默认折叠；点击节点展开，点击画布空白处折叠。
- 无结果、1 张结果和 2–4 张结果始终使用参考图中同一套节点外壳、宽度、高度和连接点位置，不因结果数量改变整体结构。
- 未生成结果时使用参考图的紧凑空态图标，不显示巨大空白预览区。
- 展开状态从上到下为：标题、真实素材缩略图槽（最多 20）、提示词、统一参数栏。
- 展开编辑区必须紧贴节点主体，视觉上是一体结构，不允许成为分离的浮动卡片。
- 参数栏顺序为：模型、比例（含 AUTO）、清晰度、数量、生成按钮；视频使用同一视觉规范。
- 生成中按钮切换为停止；生成完成后才出现结果预览。
- 默认结果布局为一宫格；选择生成 2、3、4 个结果时，在同一固定预览区切换为对应的 2、3、4 宫格。
- 生图最多显示 4 张图片，视频生成最多显示 4 个视频；每个格子保持素材原始比例，节点外壳尺寸保持不变。
- 保留左右连接点、连线中部断开按钮和拉线到空白处的添加节点菜单。
