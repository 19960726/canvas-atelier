# 画布交互统一设计

## 目标

只保留当前 Figma UI Gate 画布交互，统一选择、节点展开、媒体上传、弹层关闭和反推结果流转规则，去掉重复、持久占位或互相冲突的旧控件。

## 左键框选

- 用户在画布空白处按住鼠标左键并拖动时立即显示框选区域。
- 与框选区域相交的所有未锁定节点进入选中状态。
- 被选节点可整体拖动、复制或删除；锁定节点不参与整体移动和删除。
- `Shift` 点击或框选用于追加、取消节点选择。
- 单击画布空白处清除当前选择。
- `Escape` 清除选择并关闭临时弹层。
- 左键拖动不再平移画布；画布平移使用 `Space + 左键拖动` 或鼠标中键。
- 滚轮继续缩放画布。

## 生成节点展开与折叠

- 点击图片生成或视频生成节点卡片的非控件区域，节点进入展开编辑状态。
- 不要求用户点击预览图片才能展开。
- 点击输入框、模型、比例、清晰度、数量、生成按钮和媒体图槽时保持展开。
- 点击端口、拉线或连线断开按钮不改变节点展开状态。
- 点击画布空白处时，所有图片生成和视频生成编辑器恢复折叠状态。
- 双击生成图片只打开按原图比例显示的完整预览，不改变节点展开状态。
- 点击节点不得改变画布缩放比例或突然放大节点。
- 图片生成和视频生成使用同一套展开、折叠和焦点规则。


## 视频生成主按钮

- 视频生成节点展开后必须始终显示主按钮“生成视频”。
- 主按钮的位置、宽度、高度、圆角、文字对齐和颜色规则与图片生成节点一致。
- 任务处于排队、提交或生成中时，按钮文案切换为“停止生成”，点击只取消当前视频节点的活动任务。
- 缺少模型、提示词或必要素材时按钮保持可见但禁用，并在附近显示明确原因。
- 折叠预览状态不额外显示底部操作按钮。

## 左侧工具栏间距

- 左侧工具栏所有图标按钮使用同一宽高、圆角和图标居中规则。
- 常用画布工具按固定 12px 间距连续排列，不使用 `space-between` 将按钮拉满整列高度。
- 历史与设置作为底部分组，组内保持 12px 间距，与上方主工具组之间使用明确分组留白。
- 深色和浅色主题使用相同几何尺寸，激活、悬停和禁用状态不得改变按钮位置。
- 增加框选后不新增独立框选按钮；左键空白拖动直接进入框选。

## 空白画布启动规则

- 首次启动、点击“新建项目”和创建无模板项目时显示真正的空白画布，不自动创建图片输入、图片生成、视频生成、反推或结果节点。
- 空白画布只显示简洁的双击添加节点提示、左侧工具栏和顶部项目栏。
- 用户可以通过双击空白、左侧添加按钮、模块库或 MCP 工作流计划创建第一个节点。
- 打开已有项目时保留并恢复该项目自己的节点和连线，不清空用户数据。
- 旧项目迁移不得把示例工作流重新注入已经为空的项目。

## 图片上传

### 手动验收页面

- 浏览器手动验收页面必须弹出真实系统文件选择器，不能依赖预先排队的 E2E 测试素材。
- 支持 PNG、JPEG、WebP 和 GIF。
- 文件选中后立即进入项目受管素材导入流程。
- 上传成功后在素材节点中按原始宽高比例显示，并在已连接的生图、视频或反推图槽中显示缩略图。

### 桌面安装版

- 继续使用桌面受管资产桥接，不向渲染层暴露绝对路径。
- 图片上传、图片剪贴板和 MP4 剪贴板流程彼此隔离。
- 取消文件选择不显示错误。
- 文件格式、大小、读取、持久化或预览失败时显示明确中文原因，不能静默无响应。

## 临时弹层统一规则

知识库选择、模型选择、图片引用、快速插入和其他下拉弹层由同一个弹层协调器管理。

- 同一时间只允许打开一个临时弹层。
- 点击另一个功能按钮时关闭当前弹层，再打开目标弹层。
- 点击节点、画布空白、顶部栏、左侧工具栏或其他面板时关闭当前弹层。
- 按 `Escape`、发送消息、切换 Agent 标签、折叠 Agent、关闭设置或完成选择后关闭弹层。
- 点击弹层内部搜索、筛选、滚动和多选不会误关闭弹层。
- 知识库与模型触发按钮保留在 Agent 输入区下方，不移动到顶部。
- 关闭后不保留覆盖画布的大型空白框。

## 反推结果节点简化

- 删除反推结果节点中的“生图模型”“生图节点”和“用结果生图”整组控件。
- 反推结果节点只负责展示结构化分析、提示词和复制结果。
- 删除分析结果区域下方的整个操作栏，不保留空白占位、分隔线或隐藏表单。
- 生图模型、比例、清晰度和生成数量只在图片生成节点中配置。
- 当反推结果用于生图时，通过工作流连接把反推提示词交给图片生成节点；图片生成节点仍由用户选择模型后执行。
- 不在反推结果节点中维护另一套模型列表或目标节点选择器。

## 设置页面整理

- 浏览器手动验收页面对桌面专属功能显示“仅桌面版可用”，不显示看似可操作但没有作用的输入框。
- 连接与恢复、应用更新、缓存路径和 MCP 状态必须来自真实桌面桥接状态。
- 禁用状态必须说明原因。

## 测试与验收

- 单元测试：框选状态、追加选择、锁定节点、展开/折叠、弹层互斥和外部点击关闭。
- 浏览器集成测试：真实文件选择器回调、上传成功、取消选择和错误提示。
- 桌面桥接测试：图片导入、图片剪贴板和 MP4 剪贴板互不调用对方适配器。
- E2E：左键框选多个节点并整体移动；点击图片/视频节点展开；点击空白折叠；视频展开状态显示生成/停止按钮；知识库和模型弹层自动关闭；反推结果不再出现重复生图控件；新建项目保持空白画布。
- 视觉验收：深色和浅色主题均无残留弹层、错位选择框或节点突然缩放。

## 非目标

- 不恢复旧主题下拉框。
- 不新增独立框选工具按钮。
- 不允许左键空白拖动同时承担平移和框选。
- 不在反推结果节点内直接运行生图。
