# 生图与视频参数栏统一设计

## 目标

修复生图节点比例按钮文字被截断、参数栏间距错乱的问题，并让生图与视频生成节点使用同一套参数控件视觉规范。保持现有业务参数与生成流程不变。

## 根因

生图参数栏同时受到多套历史 CSS 规则控制：旧规则使用 `184px 172px` 的多行网格，新比例弹层组件使用固定宽度，最终在级联覆盖后触发器被压缩，比例值显示为省略号。视频参数栏另有一套更晚、优先级更高的显式网格，因此两者尺寸和对齐方式不同。

## 统一规范

- 生图和视频参数控件统一为 38px 高、10px 圆角、相同边框、背景、文字字号与悬停状态。
- 参数值与图标在按钮内部水平、垂直居中。
- 模型控件使用剩余空间；比例、清晰度、数量使用明确的可读宽度，不允许比例值产生省略号。
- 比例弹层保持两列布局，宽 226px，紧贴对应触发器上方，并在节点范围内保持可见。
- 生图参数顺序为：模型、比例、清晰度、数量、生成。
- 视频保留其专属模式、时长、音频参数，但所有基础控件沿用同一视觉标准。
- 深色与浅色主题只切换现有设计令牌，不改变几何尺寸。

## 实现边界

- 新增共享的参数栏布局类或共享 CSS 规则，集中管理两类节点的几何规范。
- 删除或覆盖导致生图参数栏回退到多行旧网格的末端规则。
- 不修改模型映射、API 请求、生成参数适配和节点数据结构。
- 不重构与本问题无关的画布、Agent、设置或历史记录代码。

## 验收

- 生图比例按钮完整显示 `AUTO`、`1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`9:16`、`16:9`。
- 生图清晰度可选择 `2K`、`4K`。
- 生图与视频参数栏的高度、圆角、间距、文字和图标对齐一致。
- 比例菜单打开后不遮挡错误区域、不被节点裁切。
- 深色、浅色主题分别截图验证。
- 自动化测试覆盖触发器可读宽度、统一高度和菜单交互。
