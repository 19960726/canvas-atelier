# 节点感知生图 Agent 与知识库成长设计

日期：2026-08-08

## 执行前提

本设计在 Comfly 与 RelayMe 双供应商接入完成并通过用户页面验收后执行。

## 目标

Agent 只负责生图相关工作，能够理解当前画布节点、连线、图槽素材顺序和模型参数，先生成可检查的工作流预览，用户确认后再通过可撤销事务写入画布。生成完成后，Agent 可根据用户反馈生成知识库升级候选，但只有用户审核通过的版本才参与跨设备同步。

## 节点理解范围

Agent 可读取素材输入、生图、图片预览、反推 Agent、反推结果和知识库节点，并理解节点连接、图槽 `1–20` 顺序、`@序号`、供应商、模型、比例、清晰度、数量、视频参数和提示词状态。

## 对话与工作流预览

- 用户可纯文本对话，也可粘贴、上传或 `@序号` 引用图片/视频。
- 用户可不选知识库、选择一个或同时选择两个知识库。
- 用户可不选择反推模型，直接使用 Skill/知识库对话整理提示词，再选择生图模型。
- Agent 回复只围绕生图、反推和知识库辅助。
- Agent 先返回结构化预览，列出将新增、修改和连接的节点，以及使用的供应商、模型、智能尺寸适配结果和素材引用。

## 用户确认与可撤销事务

- 只有点击“确认应用”后才写入画布。
- 一次确认对应一个原子事务，失败时全部回滚，完成后可撤销。
- 默认不删除已有节点，不覆盖未确认的提示词、模型和参数。
- 冲突时保留用户当前值并等待选择。

## 知识库升级候选

生成结果后，用户可给出 `KEEP`、`CHANGE`、`NEVER`。Agent 结合结果、原提示词、模型参数、知识库和反馈生成候选，显示新增规则、修改规则、来源、影响范围和冲突。候选不会自动写入；用户审核通过后生成新版本，保留旧版本、差异和回退记录。

## 跨设备同步

- 只同步用户批准的知识库版本。
- 不同步临时对话、未确认工作流、未审核候选、API Key 或本地路径。
- 两个知识库分别维护版本号和同步状态。
- 冲突显示差异并由用户选择，不能静默覆盖。

## 失败与能力不足

供应商、模型、知识库或节点能力不足时保留预览并显示具体中文原因；未确认时不调用付费生成；所有按钮必须有加载、成功、失败或禁用原因。

## 验证标准

- Agent 能从空画布和复杂画布生成确定性预览。
- 未确认时画布零修改；确认后只提交一次事务；撤销恢复原状态。
- `1–20` 图槽和 `@序号` 在 Agent、反推和生成请求中身份一致。
- 零个、一个和两个知识库路径均有测试。
- KEEP/CHANGE/NEVER 候选可审核、批准、回退。
- 跨设备只传输已批准版本。
- 中文错误、浅色/深色 UI、浏览器用户验收全部通过。

## 非目标

Agent 不自动删除节点、不未经确认运行付费生成、不未经审核学习或同步知识库，也不接管生图以外的系统操作。
