# 原创节点与 Agent 工作台改版

## 目标

以成熟创作画布软件常见的工作流为参考，重新组织节点与 Agent 对话的信息层级；功能体验对齐，但不复制第三方代码、品牌、图标、素材或逐像素布局。

## 节点工作台

- 所有可执行节点使用统一的三段结构：状态标题栏、可折叠配置主体、结果与端口区。
- 标题栏展示节点类型、已选模型、运行状态和可用操作；不把关键状态藏在 hover 中。
- 配置区优先显示完成一次运行所需的字段，高级项放在折叠区域。
- 生图节点保留提示词、模型、受管媒体输入、生成/取消与结果栅格。
- Agent 反推节点保留一次应用任务、受管媒体、知识库与项目记忆快照、开始反推及节点内结果；它仍是媒体反推的唯一入口。
- 输入、输出和错误使用清晰、固定的位置；运行过程不得改变节点位置、连线、选择状态或 viewport。

## Agent 对话工作台

- 右侧面板采用内容优先的聊天工作台：紧凑标题区、模型状态、可收起上下文、滚动消息区和固定输入区。
- 用户消息、Skill 建议、来源与只读节点反推结果具有不同的视觉层级，不使用重复的表单卡片。
- 上下文仅显示已选择知识库与项目记忆的安全摘要；正文、路径、URL、base64 和凭据不进入渲染端。
- 聊天仅提供分析与可复制建议，不能创建或修改节点、连线、选择状态或 viewport。
- 不显示伪停止操作；仅在 Provider 将来实际声明并实现取消能力时增加对应控件。

## 视觉原则

- 深浅主题均使用当前项目令牌；以清晰层次、留白、排版和状态色建立质感，而非模仿第三方视觉资产。
- 节点和面板采用一致的圆角、边界、焦点态和键盘可达性；1366×768 起不遮挡关键控件。
- 运行、成功、失败和只读状态有可见文本与非颜色提示。

## 验收

- 节点测试覆盖关键配置、运行、取消/错误与结果持久化。
- Agent 测试覆盖聊天路由筛选、上下文、消息、来源和不修改画布。
- CanvasWorkspace 测试确认布局重构后仍保留节点操作与面板焦点。
- 运行 focused Vitest、类型检查以及视觉回归；不改变 IPC 安全约束。

- 保留现有未提交改动；不 reset、clean、checkout 或提交。
- 不发布、不安装、不调用真实自动更新或付费 Provider。
