# Photoshop 2019+ 智能对象导入设计

## 状态

2026 年 8 月 12 日已确认设计方向。本规格只覆盖“将生成图片导入当前 Photoshop 文档”这一项功能，不扩展到视频导入、自动创建 PSD、自动保存 PSD 或任意 Photoshop 脚本执行。

## 目标

在 Windows 桌面版画布中，用户可右键任意已完成的生成图片，将该图片对应的受管原始文件导入当前正在使用的 Photoshop PSD/PSB 文档，并创建为嵌入式智能对象图层。

导入必须满足：

- 支持 Photoshop 2019（20.x）及以上版本；
- 使用生成结果的原始受管图片，不使用预览缩略图；
- 保持图片原始宽高比，不拉伸、不裁切；
- 小于活动 Photoshop 画布的图片保持原始像素尺寸并居中；
- 大于活动 Photoshop 画布的图片按比例缩小到画布范围内并居中；
- 不自动新建、保存、覆盖或关闭用户的 PSD/PSB；
- 不读取、写入或替换系统剪贴板内容。

## 用户交互

1. 用户在生成完成的图片上点击右键。
2. 现有“图片操作”菜单显示“导入 Photoshop（智能对象）”。
3. 只有桌面桥接可用、资产原图存在且当前没有相同导入任务时，该按钮才可点击。
4. 点击后按钮进入“正在导入…”状态，防止重复提交。
5. Photoshop 确认图层放置完成后，画布显示“已导入当前 Photoshop 文档”。
6. 导入失败时保留原图片和菜单功能，并显示可操作的中文错误原因。

浏览器开发模式不伪装成真实 Photoshop 集成。浏览器测试只使用显式 mock 验证交互和错误映射。

## 推荐架构

### Renderer

Renderer 只负责菜单、忙碌状态和通知。请求中只提交：

- 不透明的项目或会话标识；
- 受管图片资产 ID。

Renderer 不提交本地路径、脚本正文、shell 命令、Photoshop 程序路径或任意用户代码。

### Preload 与 IPC 合约

在 `window.novusDesktop.projectImages` 下增加固定方法，例如：

```ts
importGeneratedImageToPhotoshop(input: {
  sessionId: string;
  assetId: string;
}): Promise<PhotoshopImportResult>
```

IPC 使用固定通道和可判别联合响应。响应只返回成功状态、固定错误码和经过清理的显示信息，不暴露本地绝对路径或脚本内容。

### Desktop Core

新增独立 `PhotoshopSmartObjectService`，职责限定为：

1. 校验会话、资产归属和媒体类型；
2. 从项目仓库解析受管原始图片；
3. 校验解析后的文件仍位于允许的受管目录内；
4. 发现 Photoshop 2019+ 安装或正在运行的受支持实例；
5. 检查当前实例是否存在活动 PSD/PSB 文档；
6. 调用固定 Photoshop 适配器执行智能对象放置；
7. 将底层结果映射为稳定的中文错误码和提示。

项目仓库、Photoshop 发现器、自动化执行器均通过接口注入，以便单元测试不启动真实 Photoshop。

### Photoshop 适配器

首版使用与 Photoshop 2019+ 兼容的固定 ExtendScript/JSX 模板。模板内容由应用维护，不接受 Renderer 或用户提供的脚本。

资产路径通过结构化、严格转义的参数文件或固定编码参数传入，禁止把用户文本直接拼接进可执行脚本。

适配器执行以下动作：

1. 取得当前活动文档；
2. 将原始图片作为嵌入式智能对象放置；
3. 读取新图层边界与活动画布尺寸；
4. 若图片任一方向超出画布，按 `min(canvasWidth / layerWidth, canvasHeight / layerHeight)` 等比例缩小；
5. 将图层中心对齐到活动画布中心；
6. 使用安全的资产标签作为图层名；
7. 返回明确的成功标记。

如果放置或后续变换失败，适配器返回失败；不得把半完成状态报告为成功，也不得自动保存或关闭当前文档。

## Photoshop 发现规则

- 仅支持 Windows。
- 最低版本为 Photoshop 2019（主版本 20）。
- 优先连接当前正在运行且有活动文档的受支持实例。
- 如果存在多个受支持版本，优先选择正在运行的最高版本；没有运行实例时只报告可启动能力，不静默启动。
- 未安装、未运行、版本过低和无活动文档必须区分处理。

## 返回结果与错误提示

响应使用固定错误码：

| 错误码 | 中文提示 | 用户下一步 |
| --- | --- | --- |
| `desktop_bridge_unavailable` | 当前环境不支持 Photoshop 导入 | 使用 Windows 桌面版 |
| `asset_not_found` | 原始生成图片不存在，请重新生成或重新导入 | 恢复资产后重试 |
| `asset_not_owned` | 当前项目无权使用这张图片 | 从正确项目重新操作 |
| `unsupported_media` | 只有生成图片可以导入 Photoshop | 选择图片结果 |
| `photoshop_not_installed` | 未找到 Photoshop 2019 或更高版本 | 安装受支持版本 |
| `photoshop_not_running` | 请先启动 Photoshop 并打开目标文档 | 启动 Photoshop 后重试 |
| `photoshop_version_unsupported` | 当前 Photoshop 版本过低，仅支持 2019 及以上版本 | 升级 Photoshop |
| `no_active_document` | 请先在 Photoshop 中打开 PSD 或 PSB 文档 | 打开目标文档后重试 |
| `automation_denied` | Photoshop 拒绝了自动化操作，请检查权限设置 | 调整权限后重试 |
| `placement_failed` | 图片未能导入 Photoshop，请重试 | 保留画布结果并重试 |
| `import_busy` | 这张图片正在导入 Photoshop | 等待当前任务完成 |

底层异常、程序路径、用户名、项目路径和脚本栈不得直接显示给 Renderer。

## 安全边界

- Renderer 不能提交任意文件路径。
- Desktop Core 必须重新解析资产 ID，并验证真实路径属于当前项目或可信历史资产目录。
- 不执行 Renderer 或用户提供的 JSX、命令行或 shell 片段。
- 固定脚本不得包含提示词、文件名以外的自由文本；文件名也必须经过安全清理。
- 不触碰系统剪贴板，因此不会与桌面复制图片、复制视频、Agent 粘贴或画布粘贴功能冲突。
- 不自动保存、覆盖、关闭或创建 Photoshop 文档。
- 视频、外部任意路径文件和缺失原图均拒绝导入。

## 状态与并发

- 同一 `sessionId + assetId` 同时只允许一个导入任务。
- 不同图片可排队执行，但 Photoshop 自动化适配器按顺序处理，避免同时操作活动文档。
- Renderer 在请求期间禁用对应菜单项。
- 超时只结束画布侧等待并报告失败，不将未知状态当作成功。
- 导入任务不写入系统剪贴板，不改变生成历史，也不删除或移动受管原图。

## 测试策略

### 合约测试

- IPC 通道、请求字段和响应联合类型稳定。
- Preload 只暴露受限方法。
- 不允许请求中包含任意路径或脚本。

### Desktop Core 单元测试

- 正确解析当前项目中的受管生成图片。
- 拒绝不存在、越界、非图片和不属于当前项目的资产。
- 正确选择 Photoshop 2019+ 实例。
- 区分未安装、未运行、版本过低和无活动文档。
- 同一图片重复提交返回 `import_busy`。
- 自动化异常映射为固定错误码。

### Photoshop 适配器契约测试

- 小图保持原尺寸并居中。
- 横向、纵向和方形大图都等比例缩小到画布范围内。
- 不裁切、不变形。
- 创建的是嵌入式智能对象而不是链接对象。
- 不调用保存、新建或关闭文档操作。

### Renderer 测试

- 可用时显示并启用菜单项。
- 浏览器模式或资产缺失时正确禁用并解释原因。
- 点击一次只提交一次。
- 显示正在导入、成功和各类中文失败提示。
- 原有下载、发送到 Agent、图片双击预览和剪贴板功能不回退。

### 实机验收

正式验收必须在 Windows 上完成，至少覆盖 Photoshop 2019 和一个较新版本：

- 当前 PSD 和 PSB 各一次；
- 横图、竖图、方图；
- 小于画布和大于画布的图片；
- Photoshop 未运行；
- Photoshop 已运行但无活动文档；
- 导入后确认智能对象类型、图层名称、比例、尺寸和居中位置；
- 导入前后的系统剪贴板内容保持不变。

## 验收标准

1. 生成图片右键菜单提供可用的“导入 Photoshop（智能对象）”。
2. Photoshop 2019+ 当前活动 PSD/PSB 能收到受管原始图片。
3. 新图层是嵌入式智能对象。
4. 小图原尺寸居中，大图按比例缩小适配并居中。
5. 不拉伸、不裁切、不使用缩略图。
6. 不自动新建、保存、覆盖或关闭 Photoshop 文档。
7. 不读取或修改系统剪贴板。
8. 所有失败状态均显示明确中文原因并可重试。
9. Renderer 无法提交任意路径、脚本或命令。
10. 单元、合约、Renderer 回归和 Windows Photoshop 实机验收全部通过后，才可声明该功能正式完成。

## 非目标

- 将视频导入 Photoshop；
- 导入为链接智能对象；
- 自动创建新 PSD；
- 自动保存、覆盖或关闭 PSD/PSB；
- 自动选择非活动文档；
- macOS Photoshop 支持；
- 任意 Photoshop 脚本或插件市场能力；
- 使用剪贴板作为图片传输通道。
