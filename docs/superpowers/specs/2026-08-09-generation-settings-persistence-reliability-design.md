# 生图/视频参数与桌面可靠性修复设计

日期：2026-08-09

## 目标

统一生图与视频生成节点的参数选择体验，并修复模型选择、API 密钥保存、画布保存和单击关闭无响应的问题。所有交互必须在深色与浅色主题下保持一致。

## 参数选择器

### 比例

生图和视频使用同一套自定义弹层，不再使用系统原生下拉菜单。触发按钮显示比例图标、当前值和展开箭头。弹层采用双列布局，包含 AUTO、1:1、2:3、3:2、3:4、4:3、9:16、16:9；仅显示当前模型支持的选项。选中项使用主题强调色、边框和图标状态，点击画布空白或其他控件后关闭。

AUTO 根据首个已连接素材的原始宽高比推导；没有素材时交给模型使用默认比例。

### 清晰度

生图和视频使用相同外观的清晰度按钮和单列弹层。选项为 1K、2K、4K；仅显示当前模型支持的档位。选中项显示勾选图标。提交任务时将显示值映射为供应商实际参数，不在 UI 中暴露供应商名称。

### 视频专属参数

视频保留模型、生成模式、时长、音频和数量，但视觉规格与生图底部参数栏一致。比例和清晰度必须复用同一组件，避免两套行为分叉。

## 设置与模型

供应商设置重新组织为：供应商选择、连接状态、API 服务地址、凭据状态、隐藏密钥操作、模型目录。减少大块空白和不必要的说明文字。

保存密钥时按钮立即进入“正在保存”，设置明确超时；成功后关闭密钥弹窗、刷新供应商状态和模型目录并显示成功信息。失败或超时时弹窗保持打开、输入不丢失并显示具体错误。

模型目录加载后，生图、视频、反推和 Agent 对话只显示模型名称。模型选择必须可点击，并持久保存当前路由。更换密钥、接口地址或供应商后清除旧目录缓存并重新发现模型。

## 项目保存

顶部“保存项目”是显式保存操作。未命名画布即使没有节点或没有待提交自动保存，也必须进入首次创建流程，打开保存位置选择并创建真实项目。保存成功后更新项目生命周期、版本列表和状态提示。取消选择、磁盘错误或桥不可用都要产生可见反馈，不能静默无响应。

## 单击关闭

顶部关闭按钮触发受控桌面关闭请求，而不是直接依赖重复的 `window.close()`。一次点击只创建一个关闭事务：

- 已保存项目：立即关闭。
- 未保存项目：显示一次保存/放弃/取消选择。
- 保存失败或渲染端无响应：主进程超时后显示一次恢复选择，不要求重复点击。

按钮在关闭事务运行时禁用，避免并发关闭请求。

## 错误与状态反馈

项目保存、密钥保存、模型加载和关闭均提供 loading、success、error 状态。错误信息留在当前操作区域，不能只写入不可见日志。

## 验收标准

1. 生图与视频的比例弹层视觉、键盘操作和关闭行为一致。
2. 生图与视频的清晰度弹层均能选择并提交 1K/2K/4K 中模型支持的档位。
3. 保存有效密钥后弹窗关闭、状态变为已配置、模型列表可选择。
4. 密钥失败或超时时弹窗保留并显示错误。
5. 空白未命名画布点击保存也会进入真实创建流程。
6. 保存成功后画布管理出现可恢复版本或明确的已保存状态。
7. 关闭按钮单击一次即可完成关闭或显示一次决策弹窗。
8. 关键单元测试、类型检查、生产构建和 Windows 安装包构建全部通过。

## 不在本轮范围

不更改供应商计费策略，不嵌入用户真实密钥，不新增未在供应商目录中发现的虚构模型。
